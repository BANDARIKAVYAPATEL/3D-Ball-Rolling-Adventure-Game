3D Ball Rolling Adventure – Unity Game Project

Developer: Bandari Kavya

About the Project

3D Ball Rolling Adventure is a Unity-based 3D game where players control a rolling ball, collect coins, avoid obstacles, and complete challenging levels.

Key Features

- 3D ball movement and controls.
- Coin collection system with sound effects.
- Different backgrounds for different levels.
- Increasing difficulty.
- Obstacles and collision detection.
- Game-over and restart functionality.
- Level completion and progression.

Technologies Used

- Unity 3D
- C#
- Visual Studio
